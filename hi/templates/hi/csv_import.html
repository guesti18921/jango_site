Как подготовить CSV

  1. Скачайте шаблон CSV {% if perms.hi.view_mediacontent %}или экспорт текущих данных{% endif %}.
  2. Заполните таблицу, сохранив заголовки колонок.
  3. Загрузите файл и проверьте предпросмотр.
id
Пусто — новая запись. Существующий ID — обновление.
title / description
Название (до 200 символов) и описание.
image
Путь к существующему файлу, например uploads/photo.jpg.
author
Логин существующего пользователя или пустое значение.
is_published
1 — опубликовано, 0 — скрыто. Также true / false.

CSV переносит данные о материалах. Сами изображения должны уже находиться в папке media/uploads сервера. Импорт не удаляет записи.
